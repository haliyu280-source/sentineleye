# API reference

The complete, always-current reference is generated by FastAPI at **`/docs`** (Swagger UI) and
**`/redoc`**, with the raw schema at `/openapi.json`. This page summarises the endpoints and shows
typical calls.

```bash
API=http://127.0.0.1:8000
ADMIN="Authorization: Bearer $SENTINELEYE_ADMIN_TOKEN"
```

Timestamps are ISO 8601 in UTC (`2026-10-31T00:21:25.223395Z`). Errors are JSON:
`{"detail": "..."}`.

## Authentication

| Caller | Header | Used for |
|---|---|---|
| Operator / dashboard | `Authorization: Bearer <SENTINELEYE_ADMIN_TOKEN>` | everything under `/api` except the two below |
| Agent | `Authorization: Bearer se_<token_id>_<secret>` | `POST /api/agent/metrics` |
| none | | `GET /api/health`, `GET /healthz`, `/docs` |

Admin endpoints return `503` when no admin token is configured, `401` for a missing or wrong
token, and `429` after 10 failed attempts per minute from one address.

## Original endpoint

### `GET /api/health`

Runs `sentinel.sh` on the central host. Unchanged contract, plus per-check fields:

```json
{
  "operating_system": "Darwin",
  "disk_usage": 25,
  "cpu_usage": 14.3,
  "memory_total_mb": 8192,
  "status": "healthy",
  "disk_status": "healthy",
  "disk_threshold": 80,
  "cpu_status": "healthy",
  "cpu_threshold": 80
}
```

A check in warning returns `200` with `"status": "warning"`. `500` means the script could not run
or produced invalid JSON.

## Servers

```bash
# Register (returns the agent token once)
curl -s -X POST $API/api/servers -H "$ADMIN" -H "Content-Type: application/json" \
  -d '{"name":"web-01","environment":"production","thresholds":{"cpu":90}}'

curl -s $API/api/servers -H "$ADMIN"                      # list, with status and latest sample
curl -s $API/api/servers/1 -H "$ADMIN"                    # one server
curl -s -X PATCH $API/api/servers/1 -H "$ADMIN" -H "Content-Type: application/json" \
  -d '{"enabled":false}'                                  # disable (history kept)
curl -s -X PATCH $API/api/servers/1 -H "$ADMIN" -H "Content-Type: application/json" \
  -d '{"thresholds":{"memory":null}}'                     # null = back to the global default
curl -s -X DELETE $API/api/servers/1 -H "$ADMIN"          # delete with all history (204)
```

| Method | Path | Notes |
|---|---|---|
| `POST` | `/api/servers` | `201` with `server` and `agent_token`; `409` if the name exists |
| `GET` | `/api/servers` | `?include_disabled=false` to hide disabled servers |
| `GET` | `/api/servers/{id}` | status, reported system info, effective limits, latest sample, active alert count |
| `PATCH` | `/api/servers/{id}` | `name`, `description`, `environment`, `enabled`, `thresholds` |
| `DELETE` | `/api/servers/{id}` | removes tokens, metrics and alerts |

### Tokens

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/servers/{id}/tokens` | token ids and dates only, never secrets |
| `POST` | `/api/servers/{id}/tokens` | issue an additional token (existing ones stay valid) |
| `POST` | `/api/servers/{id}/tokens/reissue` | revoke all active tokens and issue one replacement |
| `POST` | `/api/servers/{id}/tokens/{token_id}/revoke` | revoke one token |

## Monitoring

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/servers/{id}/status` | `status`, `last_seen_at`, `seconds_since_last_seen`, active alert kinds |
| `GET` | `/api/servers/{id}/metrics/latest` | `404` if the agent has not reported yet |
| `GET` | `/api/servers/{id}/metrics?range=1h` | `range`: `1h`, `6h`, `24h`, `7d` |
| `GET` | `/api/overview` | server counts by status, fleet averages, active alert counts |

History responses include `raw_samples` and `bucket_seconds`. When a range holds more than 360
samples they are averaged into equal time buckets (`samples` per point says how many).

```bash
curl -s "$API/api/servers/1/metrics?range=24h" -H "$ADMIN"
```

## Alerts

```bash
curl -s "$API/api/alerts?status=active" -H "$ADMIN"
curl -s $API/api/alerts/3 -H "$ADMIN"                                  # with event timeline
curl -s -X POST $API/api/alerts/3/acknowledge -H "$ADMIN" -H "Content-Type: application/json" \
  -d '{"note":"Looking into it"}'
curl -s -X POST $API/api/alerts/3/resolve -H "$ADMIN"
curl -s "$API/api/alert-events?limit=20" -H "$ADMIN"                   # history across servers
```

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/alerts` | filters: `status` (`open`, `acknowledged`, `resolved`, `active`, `all`), `server_id`, `kind`, `limit` |
| `GET` | `/api/alerts/{id}` | alert plus `events` |
| `POST` | `/api/alerts/{id}/acknowledge` | only from `open`; otherwise `409` |
| `POST` | `/api/alerts/{id}/resolve` | from `open` or `acknowledged`; `409` if already resolved |
| `GET` | `/api/alert-events` | newest first; `server_id`, `limit` |

Kinds: `cpu_high`, `memory_high`, `disk_high`, `server_offline`.

## Agent ingestion

### `POST /api/agent/metrics`

```json
{
  "server_id": 3,
  "collected_at": "2026-10-31T00:21:25.120000+00:00",
  "hostname": "web-01",
  "agent_version": "1.0.0",
  "os": {"name": "Ubuntu", "version": "24.04", "kernel": "6.8.0-45-generic"},
  "uptime_seconds": 86400.5,
  "cpu_percent": 12.4,
  "memory": {"total_bytes": 4106604544, "used_bytes": 829083648, "available_bytes": 3277520896, "percent": 20.19},
  "disk": {"mount": "/", "total_bytes": 240120725504, "used_bytes": 1559810048, "available_bytes": 226288857088, "percent": 0.68},
  "delivery": {"failed_attempts": 0, "last_error": null}
}
```

| Response | Meaning |
|---|---|
| `202` | `{"accepted": true, "server_status": "healthy"}` |
| `401` | missing, malformed, unknown, revoked or expired token |
| `403` | token belongs to another server, or the server is disabled |
| `409` | sample is not newer than the last accepted one (duplicate or replay) |
| `413` | body larger than 64 KB |
| `422` | invalid payload, or `collected_at` more than 5 minutes from the backend's clock |
| `429` | more than 30 reports per minute for this token |
